# Telecom Customer Analytics Dashboard | Power BI

## Project Overview
An interactive Telecom Customer Analytics Dashboard developed using Microsoft Power BI to analyze customer behavior, churn, revenue, network performance, and digital engagement.

## Dashboard Modules
1. Customer Overview & Churn
2. Customer Value
3. Customer Lifecycle
4. Usage Analytics
5. Revenue & Billing
6. Network & Experience
7. Digital Engagement

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Key Features
- Interactive KPI cards
- Customer churn analysis
- Revenue and billing insights
- Customer segmentation
- Network performance monitoring
- Digital engagement analysis
- Interactive filters and slicers

## Project File
Download the `.pbix` file from this repository and open it using Microsoft Power BI Desktop.
